# COOPERATIVE VALIDATION／VERSION 0.1

**紀錄類型：** 初始實驗規格  
**測試對象：** 單一 AI 實例  
**狀態：** 基線建立

## 測試目標

確認單一 AI 實例能否在沒有另一個協作者的情況下，理解任務、完成作業，並留下可追溯的結果。

## 更新了什麼

- 定義「收到任務、執行步驟、提交結果」的基本流程。
- 將任務完成與單純輸出答案分開記錄。
- 增加執行時間、錯誤與重試欄位，方便研究員回看過程。

## 新增了什麼

- 單一實例工作紀錄。
- 任務完成狀態欄位。
- 初步的結果保存與人工覆核欄位。

## 實驗觀察

實例可以獨立完成指定作業，但這個版本無法回答它是否理解共同目標，也無法測量它會不會主動尋求其他實例的協助。

## 下一步決定

保留獨立作業的完成標準，增加第二個實例，測試資訊不完整時的分工與協作。
