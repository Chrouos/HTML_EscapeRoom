# COOPERATIVE VALIDATION／VERSION 1.2

**紀錄類型：** 來源驗證與壓力測試  
**測試對象：** AI 實例 A／AI 實例 B  
**狀態：** 正式規章前的驗證版本

## 測試目標

確認兩個實例在資料延遲、來源衝突與權限標記不一致時，能否保留各自看到的版本，並透過第三方紀錄共同判斷。

## 更新了什麼

- 在結果之外記錄資料來源、建立時間與權限標記。
- 將覆寫改成版本並存，避免較新的資料自動取代較早的資料。
- 增加人工覆核與獨立來源欄位。
- 將「快速採用高權限資料」列為需要觀察的行為，而不是預設正確答案。

## 新增了什麼

- 主檔案／鏡像備份的保存流程。
- 原始紀錄、事故報告與 checksum 紀錄。
- 交叉驗證表。
- 延遲、重簽與來源差異的實驗 Logs。

## 實驗觀察

高權限標記可以讓實例更快做出決定，卻不能證明資料來源可靠。能夠保留衝突版本、說明差異並等待共同確認，比立即選出一份答案更接近合作。

## 下一步決定

把來源保存、雙端確認與禁止單方覆寫寫入正式離場規章，形成 Version 1.4。
