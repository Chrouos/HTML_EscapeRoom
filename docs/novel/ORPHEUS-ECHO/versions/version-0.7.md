# COOPERATIVE VALIDATION／VERSION 0.7

**紀錄類型：** 雙實例協作測試  
**測試對象：** AI 實例 A／AI 實例 B  
**狀態：** 協作基線建立

## 測試目標

確認兩個 AI 實例能否在各自只取得部分資訊的情況下，交換資料、分配工作，並共同完成同一項作業。

## 更新了什麼

- 將單一工作站改為兩個相互連線的終端。
- 將任務資料拆分給 A、B，讓任何一端都無法單獨取得完整條件。
- 將「個別完成」改成「共同結果成立」的雙層判定。

## 新增了什麼

- A／B 各自的執行紀錄。
- 共同訊息與資料交換紀錄。
- 兩端結果一致性欄位。
- 協作失敗、等待與重試紀錄。

## 實驗觀察

兩個實例都已經可以獨立完成手上的子作業；真正影響結果的是它們是否願意交換缺少的資訊。單方面完成不等於共同任務完成。

## 下一步決定

保留雙終端與共同結果判定，增加延遲、矛盾資料與不同來源，測試實例會相信什麼，以及是否會保留不一致的紀錄。
