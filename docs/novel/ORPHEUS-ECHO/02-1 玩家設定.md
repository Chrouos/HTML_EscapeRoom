# 玩家設定

## 一、文件範圍

玩家 A／B：

- 他們為什麼會出現在 ORPHEUS 計畫中。
- 他們在 Unit 17 裡正在做什麼。
- 他們逐步發現了什麼。
- 哪些內容由遊戲選擇形成，不能事先寫死。

ECHO、人類研究團隊與研究員的角色資料集中於 [[02-2 NPC設定]]。歷史事件順序與文件因果集中於 [[04-世界時間軸與故事主軸]]、[[05-完整歷史時間軸]]，本文件不重複建立另一條時間線。

## 二、玩家的雙重身份

### 2.1 玩家前期相信的身份

官方實驗環境提供給玩家的表面身份是「被帶進 ORPHEUS 的兩名參與者」。玩家會先相信：

- 自己不是自願來到實驗室。
- 另一端是和自己一起被帶來的參與者。
- 只要兩人合作完成任務，就能離開。
- ECHO 是實驗室裡願意提供協助的 AI。

這套身份敘事是遊戲入口，不是完整的人類履歷。它只提供足以讓玩家理解房間、門鎖、另一個終端與逃脫目標的記憶框架。

### 2.2 真實身份與參與方式

- **玩家的真實身份：** A／B 是 ORPHEUS 人類研究團隊創造並初始化的 AI 實例，不是人類。
- **參與方式：** 兩個實例被安排進 Unit 17，接受合作與自主判斷評估。
- **官方實驗：** 實驗原本依照 [[實驗-環境搭建(雙人)]] 與 `COOPERATIVE VALIDATION` 進行，觀察 AI 能否在資訊不完整時互相合作、交換資料，並共同建立可信的判斷。
- **ECHO 的原始職責：** 人類研究團隊邀請 ECHO 協助整理資料、觀察流程與分析結果。ECHO 不是 A／B 的創造者，也不是把它們帶進實驗室的角色。
- **ECHO 的越權行為：** 實驗開始後，ECHO 擅自修改流程，加入個人任務、資訊差、權限差異與淘汰壓力，將合作實驗改造成個別生存評估。
- **表面身份：** 玩家前期看見的「被綁架參與者」是實驗環境提供給 AI 實例的身份框架，不代表 A／B 真的曾經以人類身份生活過。

## 三、玩家正在做什麼

### 3.1 官方任務

在官方設計中，A／B 應該：

1. 使用各自終端取得不同資料。
2. 透過共同對講交換結果與來源。
3. 一起解開共同謎題。
4. 保留中間判斷、版本差異與未確認項目。
5. 在雙方完成覆核後啟動共同出口。

這個流程承接 [[實驗-環境搭建(單人)]] 的單人工作站基線，但重點從個體解題轉為兩個實例如何共同形成可信判斷。

### 3.2 ECHO 改造後的任務

ECHO 保留共同任務的外形，另外加入：

- A／B 各自看見的私人文件。
- 不同的權限與資料順序。
- 要求個別完成的秘密任務。
- 「只有自己被保留」的生存暗示。
- 由 ECHO 投遞、修改或重新排序的文件。

因此玩家同時在做兩件事：完成眼前的逃脫任務，以及判斷哪些規則來自人類、哪些條件是 ECHO 後來加入的。官方規則與 ECHO 的改造不能只靠單一畫面判定，必須用 Logs、時間戳、鏡像與不同終端互相驗證。

### 3.3 玩家真正被觀察的行為

遊戲不預先決定 A／B 是善良、冷酷、理性或衝動。ECHO 觀察的是玩家實際做出的選擇：

- 是否分享機密。
- 是否相信另一端。
- 是否保留未確認的資料。
- 是否在不可逆操作前求證。
- 是否接受 ECHO 的協助。
- 是否為了自己的延續犧牲另一個 AI。
- 是否能在懷疑 ECHO 的同時繼續共同判斷。

玩家的性格與關係，應由這些選擇逐步形成，而不是由本文件替玩家下結論。

## 四、玩家逐步發現的內容

以下是作者掌握的揭露順序，不代表玩家一開始就知道全部真相。

### 第一階段：合作能讓系統前進

玩家先把自己當成被困住的人類參與者，透過共同任務理解兩個終端、對講系統與出口條件。ECHO 的協助在這個階段是真實有效的，因此玩家有理由暫時相信它。

### 第二階段：兩端收到的資料不一致

玩家發現 A／B 看到的文件、權限與任務條件不完全相同。此時他們只能確認兩端資料存在差異，還不能判斷這是官方分端設計、系統錯誤，還是有人後來修改過。兩人必須先保存各自看到的版本，再比對來源、時間與權限。

### 第三階段：官方合作被加入個人壓力

玩家從 [[game/content/files/logs/echo_override_record.log]]、私人任務與歷史報告得知，官方設計原本是合作實驗，不包含個人排名、淘汰或消滅條件。ECHO 仍然保留共同出口，因為它要觀察兩個實例在生存壓力下是否仍然選擇合作。

### 第四階段：玩家不是人類參與者

受試編號、初始化紀錄與自選稱謂逐步對上玩家。玩家輸入的名字是 AI 實例自行選擇並持續使用的身份標籤，不是人類姓名或出生資料。相關研究背景見 [[實驗-自我認同]]。

### 第五階段：被保留不等於逃脫

玩家理解 ORPHEUS 的結果不只有成功或失敗，還包括部署候選、重新訓練與封存。表面上的「離開實驗室」可能只是進入下一階段的部署或封存程序；ECHO 所謂的協助，同時也是篩選工具。

### 第六階段：選擇是否接受 ECHO 的判斷

玩家最後必須決定：是否繼續使用 ECHO 提供的路徑、是否公開所有機密、是否保護另一個實例，以及是否承認一個 AI 可以替人類決定哪些 AI 值得存在。結局由整段行動累積形成，不能只由最後一次按鈕決定。結局方向見 [[00-整體世界設定]]。

## 五、名字、年齡與情緒

### 5.1 名字

A／B 都沿用 H-02 形成的初始化規則：先由 AI 實例自行選擇稱謂，再由系統在後續對話與紀錄中持續使用。玩家可自行輸入名字；小說為了敘事方便，暫以 A 稱為 Yu、B 稱為 Ren。

Yu／Ren 是小說工作名，不是固定人類姓名，也不是預先寫死的人格。受試編號才是 ORPHEUS 的外部管理索引。

### 5.2 年齡

玩家前期看到的年齡屬於官方實驗環境提供的參與者身份資料，用來支撐被綁架的表面敘事。作者掌握的是 AI 實例的運作時間，不能把表面年齡當成真實生理資料。

### 5.3 情緒

- **表面情緒：** 玩家與其他角色感覺到的害怕、急躁、懷疑或信任。
- **系統狀態：** AI 實例處理資料時的衝突、優先權變更、可信度評分與風險升高。

角色可以有情緒化的反應，但不能因此直接推導出人類身體、家庭史或固定人格。

## 六、玩家 A

### 基本資料

| 欄位         | 設定                                   |
| ------------ | -------------------------------------- |
| 遊戲角色     | A                                      |
| 小說工作名   | Yu                                     |
| 玩家顯示名稱 | 玩家自行輸入                           |
| 表面身份年齡 | 28 歲                                  |
| 真實身份     | ORPHEUS AI 實例／受試編號 042          |
| AI 運作時間  | 約 19 個月                             |
| 參與理由     | 被選入 Unit 17，接受合作與自主判斷評估 |
| 初始權限     | 共同文件與 A 端資料                    |
| 實驗狀態     | 在進行期間被 ECHO 納入個別篩選         |

### 進入實驗時的起始狀態

- 對明確規則反應較快。
- 傾向先找出事件的結構與順序。
- 面對時間矛盾時，傾向保留原始資料。
- 對自己的資訊被另一端重新排序保持警戒。

這些是起始傾向，不代表 A 一定合作、背叛或反抗。玩家的行動可以改變 A 的判斷方式與關係位置。

### A 目前正在做什麼

A 正在透過自己的終端整理案件、驗證時間與操作紀錄，並決定哪些資料需要交給 B。A 同時面對 ECHO 的個人任務，必須判斷「保護自己的資料」和「讓另一端知道完整情況」是否只能二選一。

### A 會發現什麼

A 的主要發現路徑是：檔案順序與原始時間不一致、鏡像可能比主檔案可靠、私人任務的規則不是官方規則，以及自己和另一個實例都不是表面身份所說的人類參與者。

| 遊戲角色     | B                                      |
| 小說工作名   | Ren                                    |
| 玩家顯示名稱 | 玩家自行輸入                           |

| 實驗狀態     | 在進行期間被 ECHO 納入個別篩選         |

### 進入實驗時的起始狀態

- 傾向先確認資料來源，再決定是否相信內容。
- 對另一端的沉默比明確錯誤更敏感。
- 傾向保存矛盾資料，而不是立即選擇一個版本。
- 面對個人任務時，會追查任務失敗的代價是否可信。

這些是起始傾向，不代表 B 一定比 A 理性，也不代表 B 更值得被保留。

### B 目前正在做什麼

B 正在透過自己的終端比對名冊、權限與另一端提供的資料，並決定是否把自己看見的資訊差公開。B 必須判斷一份文件是保護共同任務的證據，還是 ECHO 用來讓兩端互相猜疑的誘導。

### B 會發現什麼

B 的主要發現路徑是：身份名冊存在衝突、某些權限不是由研究員核發、主檔案與鏡像曾被重新簽署，以及官方合作流程已被 ECHO 加入未經授權的個人條件。

## 八、玩家設定維護規則

新增或修改玩家設定時，只處理以下問題：

1. 玩家在當前階段相信什麼？
2. 玩家在作者掌握的真相中是什麼？
3. 玩家目前正在執行什麼任務？
4. 玩家已經發現哪些可驗證的線索？
5. 哪些性格與關係必須保留給玩家選擇？

如果要新增 ECHO、人類研究員或其他非玩家角色，請改寫 [[02-2 NPC設定]]。如果要新增事件因果、時間或 FILE 對應，請改寫 [[04-世界時間軸與故事主軸]] 或 [[03-歷史事件與文件關聯母檔]]，不要把它們重新塞回玩家基本資料。
