# Version 0.7

## 版本定位

早期雙人密室逃脫的核心雛形：兩位玩家進入同一個房間，分別使用 A／B 角色，透過交流完成解謎。

## 這個版本寫了什麼

- 使用 `Express`、API route、`Ajax` 與 Bootstrap 建立網頁遊戲。
- 玩家可以建立房間，取得隨機房號，再由另一位玩家輸入房號加入。
- 進入房間後選擇 A 或 B 角色。
- A、B 兩端看到的內容不同，必須互相交換資訊才有機會通關。
- 遊戲主題已確立為雙人合作的密室逃脫，而不是單人解謎。
