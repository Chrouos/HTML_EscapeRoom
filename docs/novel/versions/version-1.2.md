# Version 1.2

## 版本定位

舊版雙人密室流程的可遊玩整理：在早期雛形上補齊房間進入、角色分流與 A／B 遊戲畫面，讓兩位玩家可以實際走完合作解謎流程。

## 這個版本寫了什麼

- 增加建立房間與加入既有房間的完整頁面流程。
- 保留 A／B 角色分工，並分別提供 A、B 的遊戲畫面。
- 擴充 API 與房間 route，讓房號、玩家進入與遊戲頁面可以串起來。
- 整理 `Views`、圖片資源、共用頁面與錯誤頁面。
- 持續以「資訊不完整，玩家必須互相溝通」作為主要遊戲方式。
- 加入舊版解答與畫面修正，讓原型更接近可展示的版本。
