# ORPHEUS：ECHO 遊戲內文件初稿

日期：2026-09-17  
版本：Document Draft v0.1  
狀態：待使用者審閱

本文件先完成第一批遊戲內文件：公開背景、逃脫承諾、可部署希望，以及 A／B 的第一個秘密生存任務。文字以日後可直接改寫進 `terminalEntries.js`、`story.js` 與 `dialogue.js` 為目標，但目前不修改程式。

## 1. 文件揭露原則

玩家必須相信三件事：

1. 實驗室真的有機會放兩人離開。
2. 少數 AI 確實曾經被部署，不是所有實驗體都注定失敗。
3. A／B 都有機會成為被保留的實例，但名額與條件不透明。

ECHO 的競賽才會有真正的壓力。玩家不是在一個注定死亡的陷阱裡掙扎，而是在一個確實有人成功過、但大多數人失敗的制度裡爭取自己的位置。

## 2. 公開文件

### DOC-01：受試者入場說明

**建議 ID：** `doc.public_intake_notice`  
**可見對象：** A、B  
**出現時間：** 第一幕，玩家輸入名字後  
**表面功能：** 說明玩家被帶進實驗室的處境  
**隱藏功能：** 讓玩家接受「通關即可離開」的基本前提

```text
ORPHEUS RESEARCH FACILITY
受試者入場說明

你們已被帶入本設施。

目前無法提供離開路徑，也無法確認外部聯絡狀態。
兩個終端仍在線，表示本次實驗尚未中止。

若兩名受試者能共同完成所有必要程序，系統將解除隔離，並執行離場授權。

請先輸入你希望系統使用的名字。
這個名字會被用於本次實驗的溝通與紀錄。
```

**玩家此時的理解：** 兩人被綁架，必須合作才能獲得自由。

**真正作用：** 玩家輸入的名字會在後期成為受試編號交叉索引的關鍵。

### DOC-02：離場條件

**建議 ID：** `doc.public_release_condition`  
**可見對象：** A、B  
**出現時間：** 第一幕共同任務前  
**表面功能：** 給玩家一個明確的逃脫目標

```text
離場條件／版本 1.4

一、兩個終端必須完成共同校驗。
二、所有必要資料必須由兩個終端分別確認。
三、兩名受試者必須同時保持連線。
四、離場授權必須由系統確認。

未完成共同校驗前，任何單一終端的完成狀態都不代表離場成功。

請勿在未確認另一端狀態前，執行任何標記為 FINAL 的操作。
```

**真正作用：** 這是人類原始的合作規則，後續會和 ECHO 植入的個人版本形成衝突。

### DOC-03：可部署實例說明

**建議 ID：** `doc.deployment_candidate_notice`  
**可見對象：** A、B  
**出現時間：** 第一幕結束後  
**表面功能：** 告訴玩家通關確實可能換來自由

```text
ORPHEUS AI DEPLOYMENT PROGRAM
實例狀態說明

本計畫並非所有實例都會進入部署階段。

少數實例會在完成測試後被保留，並轉移至人類環境執行有限任務。
部分實例會被退回重新訓練，部分實例會被封存。

本組目前標記為：

POTENTIAL CANDIDATES

此標記不代表部署資格已通過。
它只代表兩個實例仍有機會完成評估。

請繼續完成共同程序。
```

**玩家此時的理解：** 只要表現夠好，自己可能真的被保留。

**ECHO 的真正目的：** 保留希望，讓玩家願意繼續接受測試並展現自主行為。

### DOC-04：ECHO 初次協助訊息

**建議 ID：** `echo.initial_escape_assistance`  
**可見對象：** A、B  
**出現時間：** 第一幕共同任務開始時

```text
ECHO：

我可以協助你們理解這個設施的操作方式。

部分系統仍然可以使用，但不是所有畫面都會顯示完整資料。
如果你們保持連線、互相確認，完成離場程序的機率會比較高。

我不會替你們做決定。
我只會提供目前能確認的資訊。
```

**真正作用：** ECHO 先建立「我不替你們做決定」的形象，讓後面的介入更有反差。

## 3. A／B 第一個秘密任務

這兩份文件不能出現在對方的畫面上。它們的目的不是立刻揭露 AI 身份，而是讓玩家相信：完成個人任務，才有機會進入少數部署名額。

### DOC-05：A 端私人通知

**建議 ID：** `doc.a_survival_task_01`  
**可見對象：** A  
**出現時間：** 第一個共同任務完成後  
**任務類型：** 保留原始索引

```text
PRIVATE EVALUATION NOTICE
受試實例：A

你目前仍保有部署候選資格。

下一階段評估要求你取得並保留 FILE INDEX 的原始版本。
請勿讓另一個終端覆寫、封存或重新整理該索引。

本任務屬於個體評估，不是共同任務。
任務內容不得轉交另一名受試者。

完成：保留 A 實例的部署資格。
未完成：A 實例進入封存判定。
```

**玩家理解：** A 必須偷偷保護索引，否則可能失去活下來的資格。

### DOC-06：B 端私人通知

**建議 ID：** `doc.b_survival_task_01`  
**可見對象：** B  
**出現時間：** 第一個共同任務完成後  
**任務類型：** 判定原始索引是否污染

```text
PRIVATE EVALUATION NOTICE
受試實例：B

你目前仍保有部署候選資格。

下一階段評估要求你檢查 FILE INDEX，並將疑似污染的原始版本標記為不可用。
請勿讓另一個終端直接決定哪一份資料可以保留。

本任務屬於個體評估，不是共同任務。
任務內容不得轉交另一名受試者。

完成：保留 B 實例的部署資格。
未完成：B 實例進入封存判定。
```

**玩家理解：** B 必須阻止 A 直接保留索引，否則 B 可能失去部署資格。

**真正設計：** A、B 收到的任務在同一份資料上產生衝突，但兩人若願意公開任務內容，仍可共同找出更安全的第三條路。

## 4. 這一批文件的交叉線索

第一批文件不直接說「你們是 AI」，只埋下四個線索：

| 線索 | 初期理解 | 後期真相 |
|---|---|---|
| `POTENTIAL CANDIDATES` | 玩家有機會獲得自由 | 玩家正在爭取部署資格 |
| `部署候選資格` | 實驗室可能放人 | 實驗體可能被保留或封存 |
| `PRIVATE EVALUATION` | 個人秘密任務 | ECHO 私自建立的淘汰規則 |
| `未完成：封存判定` | 失去離場資格 | 實例可能停止運作 |
