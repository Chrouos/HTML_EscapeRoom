# Escape Room v2 實作紀錄

分支：`new_open`。沿用已核准的 2026-09-04 規格與計畫。

## 實作範圍

- 六個主線謎題共十四個步驟、四個可選調查共八個步驟、三種雙人共同決定的結局。
- 伺服器判定答案與身份；角色線索投影、revision 輪詢、操作去重、聊天重試與重新整理恢復。
- 單一 EJS 遊戲頁、實驗室終端樣式、響應式版面、鍵盤焦點、減少動態效果與音訊文字替代。
- 移除核准清單中的舊控制器、路由、頁面、前端腳本與被取代的 Bootstrap 樣式。歷史解答及素材保留，可由 Git 取回舊程式。
- 更新 README，新增可重建的 Morse WAV 與產生腳本。

## 分工與審查

Luna 工作者協助初版內容、引擎與前端；主執行緒整合與驗證。視覺工作者額度不足後，由主執行緒完成版面。Task 4 與 Task 7 的 API／前端先整合，以建立瀏覽器驗證入口，再完成 Task 5、6、8、9。

Sol medium 獨立審查未發現重大跨角色資料洩漏、revision 重試競態或結局繞過。主執行緒處理：

- 切換主線或支線步驟時清空上一題未送出的答案，加入雙瀏覽器回歸檢查。
- 統一字串及物件證據的去重計數，加入單元測試。
- 拒絕「空的 canonical privateClues 應退回舊 roleClues」建議，避免重新顯示已清除的舊線索。
- 修正選項型支線把所有選項當成正解的問題，加入錯誤選項測試。

## 驗證與限制

最後執行 `npm run check`：35 個單元測試、15 個整合測試、8 個瀏覽器測試全部通過，整體退出碼為 0。瀏覽器測試包含最新版主線與支線草稿清空回歸檢查。

單元與整合測試涵蓋身份、狀態隔離、倒數歸零後繼續遊玩、完整主支線與結局。瀏覽器測試涵蓋雙人通關、結局意見衝突與重選、刷新、聊天確認遺失後重試，以及三種螢幕尺寸。截圖已人工檢視桌機與手機遊戲畫面。

沙箱內 Playwright 案例通過後程序未正常退出；取得授權後在沙箱外重跑，八個案例通過且退出碼為 0。

此版本仍為本機、記憶體房間；重啟會清空進度。45 分鐘是故事倒數，未宣稱經真人驗證的遊玩時長。正式部署與持久儲存不在本次範圍。既有非 API 500 錯誤仍使用 404 樣板，此低優先度項目保留待後續處理。
