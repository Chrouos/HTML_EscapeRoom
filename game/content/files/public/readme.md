ORPHEUS RESEARCH FACILITY
UNIT 17 / PARTICIPANT PROCEDURE

本文件說明 Unit 17 的基本程序與離場條件。

本程序由兩名參與者共同進行。兩名參與者各自使用一個終端，兩個終端不會顯示完全相同的資料。

請遵守以下規則：

1. 兩個終端都必須保持連線。
2. 請交換各自看到的資料。
3. 某些步驟必須由兩名參與者共同完成。
4. 完成共同程序後，系統才會執行離場授權。
5. 如果兩個終端顯示的內容不同，請先互相確認，不要刪除任何一份資料。

開始程序前，請輸入希望系統使用的名字。
這個名字會用於本次程序的溝通、紀錄與參與者自我辨識。
